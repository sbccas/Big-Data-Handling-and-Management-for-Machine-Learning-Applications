## 3. Detailed Subject-by-Subject Analysis

### Semester-5 Subjects

#### 1. DS-501: Cloud Computing Fundamentals (Minor, 4 Credits)
* **Status across PDFs:** Content, Unit 1 to 4 topics, Course Outcomes (CO1–CO5), and reference books are **identical**.
* **Key Topics Covered:**
  - **Unit 1:** Basics of Cloud Computing, Cloud Models (IaaS, PaaS, SaaS, NaaS, DBaaS), Public/Private/Hybrid/Multi-Cloud, Business Use Cases.
  - **Unit 2:** Architecture & Virtualization (Hypervisors Type 1 & 2, Full/Para/Emulation, SOA, Utility Computing).
  - **Unit 3:** AWS & Azure Platforms (EC2 vs Azure VMs, Lambda vs Azure Functions, S3 vs Blob, RDS vs Azure SQL, DynamoDB vs Cosmos DB, VPC/VNet, IAM/AAD).
  - **Unit 4:** Cloud Security & Trends (CSA, RBAC, GDPR/HIPAA/SOC2, SLAs, OLTP vs OLAP, Data Lakes, Edge Computing, SageMaker/Azure ML).

---

#### 2. DS-502: Computer Network (Minor, 4 Credits)
* **Status across PDFs:** Identical syllabus structure, units, COs, and reference lists.
* **Key Topics Covered:**
  - **Unit 1:** Network types (LAN, MAN, WAN, PAN), Topologies, Data communication, Linux networking commands (`ping`, `traceroute`, `netstat`, `ifconfig`, `nslookup`).
  - **Unit 2:** OSI Reference Model, MAC/LLC, CSMA/CD, CSMA/CA, Switching techniques, Routing basics, Wireshark packet capture case study.
  - **Unit 3:** TCP/IP Suite, IPv4/IPv6, Subnetting, Supernetting, CIDR, VLSM, Routing (RIP, OSPF, BGP), ICMP/ARP/RARP, TCP vs UDP, MITM/DoS/DDoS, Firewalls, IDS/IPS.
  - **Unit 4:** DNS, Web Technologies (HTTP/HTTPS, APIs), Email (SMTP, POP3, IMAP), Modern Trends (Cloud Networking, SDN, IoT Networking).

---

#### 3. DS-503: Fundamentals of Machine Learning (Major, 4 Credits - Theory & Lab)
* **Status across PDFs:** Content is identical.
* **Key Topics Covered:**
  - **Unit 1:** Unsupervised Learning overview, clustering concepts, distance metrics (Euclidean, Manhattan), Python Scikit-learn environment.
  - **Unit 2:** Clustering Algorithms: K-Means (Elbow method, Scikit-learn implementation, Matplotlib visualization), Hierarchical Clustering (Agglomerative, Divisive, Dendrograms), Density-Based (DBSCAN, outlier detection).
  - **Unit 3:** Dimensionality Reduction: Curse of dimensionality, PCA (Principal Component Analysis), Feature Selection, High-dimensional visualization.
  - **Unit 4:** Introduction to Artificial Neural Networks (ANN): Biological vs Artificial Neuron, Activation functions (Sigmoid, ReLU, Tanh), Feedforward networks, Loss functions, Gradient Descent, Backpropagation, Keras/TensorFlow basics.

---

#### 4. DS-504: Advanced Data Visualization and Dashboard Development (Major, 4 Credits - Theory & Lab)
* **Status across PDFs:** Content is identical.
* **Key Topics Covered:**
  - **Unit 1:** Advanced Data Modeling & DAX in Power BI (Star/Snowflake schema, Fact & Dimension tables, active/inactive relationships, DAX measures vs columns, aggregation/logical functions).
  - **Unit 2:** Advanced Visualizations in Power BI (Drill-down, drill-through, slicers, cross-filtering, dynamic tooltips, custom marketplace visuals, maps, KPI cards).
  - **Unit 3:** Dashboard Design & Storytelling (Visual narrative layout, performance optimization, load time reduction, case studies in Sales & Customer Segmentation).
  - **Unit 4:** Tableau & Deployment (Tableau Desktop overview, Power BI vs Tableau, building visuals/dashboards, publishing to Power BI Service, access control).

---

#### 5. DS-505: Big Data Handling and Management for Machine Learning Applications (Major, 4 Credits - Theory & Lab)
* **Status across PDFs:** Content is identical.
* **Key Topics Covered:**
  - **Unit 1:** Big Data Fundamentals (3 Vs: Volume, Velocity, Variety), memory management in Python, Pandas & NumPy data handling functions.
  - **Unit 2:** Distributed Data Processing with PySpark (Apache Spark architecture, PySpark DataFrames, `spark.createSession`, `df.show()`, `df.groupBy()`, `df.select()`).
  - **Unit 3:** Big Data Preparation for ML (Data cleaning, imputation, scaling, Scikit-learn preprocessing pipelines, Linear Regression, Decision Trees, KNN).
  - **Unit 4:** Intro to LLMs & Big Data NLP (LLM concepts, Hugging Face transformers, tokenization, text cleaning, API integration, ethical considerations).

---

#### 6. DS-506: Ethics of Data Science (SEC, 2 Credits)
* **Status across PDFs:** Content is identical.
* **Key Topics Covered:**
  - **Unit 1:** Data ethics foundations, moral principles, bias/fairness in algorithms, role of data scientists.
  - **Unit 2:** Data security and privacy, data breach types, GDPR & Indian Data Protection Act, bias detection and mitigation toolkits.
  - **Unit 3:** Social impact, algorithmic colonialism, accountability in automated decision-making.
  - **Unit 4:** Real-world case studies (Facebook data controversies, AI ethical failures, audit toolkits).

---

### Semester-6 Subjects

#### 1. Minor Electives (DS-601-01 / DS-601-02) (4 Credits each)
* **DS-601-01 (E-Commerce & Cyber Security):** E-Commerce frameworks, I-Way infrastructure, electronic payment systems (e-Cash, e-wallets, credit/debit security, SSL), cybercrime taxonomy (Trojan, DoS, DDoS, spoofing, IPR violations, squatting), and cybersecurity fundamentals (DNS, firewalls, threat actors).
* **DS-601-02 (Computer Graphics):** Display hardware (CRT, LCD, DVST, raster/random scan), line generation algorithms (DDA, Bresenham, VECGEN), line styles, and 2D geometric transformations (translation, scaling, rotation about origin/homogeneous coordinates, reflection, shearing).

#### 2. DS-602: Advanced Machine Learning Models and Neural Networks (Major, 4 Credits)
* **Key Topics Covered:** Support Vector Machines (hyperplane, margin, linear/poly/RBF kernels), Ensemble Learning (Bagging, Random Forest, Gradient Boosting), Deep Neural Networks (multi-layer representation learning, regularization via Dropout & Early Stopping), TensorFlow/Keras sequential modeling, and Convolutional Neural Networks (CNNs: Conv layers, pooling, filters, image classification pipelines).

#### 3. DS-603: Big Data and Cloud-Based Machine Learning (Major, 4 Credits - Theory & Lab)
* **Key Topics Covered:** Cloud storage & notebooks (Google Colab, Google Drive mounting, remote data streaming), Model Serialization & Deployment (Pickle, Joblib, Scikit-learn pipelines), Cloud Data Integration, and REST API deployment using Flask (`route`, `request`, `jsonify`, `requests.post`).

#### 4. DS-604: Project (Major, 4 Credits)
* **Structure:** 4-stage SDLC execution: (1) Planning & Problem Definition, (2) System & Dataset Design, (3) Implementation & Cloud/ML Integration, (4) Documentation (SRS, User Manual), Deployment & Viva-Voce.
* **Evaluation Scheme:** Planning (10%), Architecture (15%), Implementation (30%), Testing/Deployment (15%), Documentation (10%), Presentation & Viva (20%).

#### 5. DS-605: Project and Interview Presentation Soft Skills (AEC, 2 Credits)
* **Key Topics Covered:** IT technical communication, presentation tools (PowerPoint, Canva, Prezi), technical report writing (IEEE/ACM formats), resume/LinkedIn optimization, STAR method for behavioral interviews, and mock viva presentations.

#### 6. DS-606: Internship (4 Credits, 120 Hours)
* **Structure:** 120 contact hours in IT industry / government / research bodies. Deliverables include Joining Report, Weekly Progress Logbook, Final Internship Report with Certificate, and Viva-Voce.

## 4. Key Additions in Document 1 (Appended SEC Courses)

A major structural difference in the **August 2026 file (Document 1)** is the inclusion of the university-wide **Skill Enhancement Course (SEC)** pool across Semesters 1 through 5 for BCA / B.Sc. IT / Data Science streams. These include:

1. **Semester 1 (AI-106-03):** Introduction to IoT Devices (Arduino, basic electronics, breadboards, sensor interfacing).
2. **Semester 3 (Course 306-01):** Exploratory Data Analysis (EDA) using Python (Data sources, Pandas cleaning, Matplotlib/Seaborn/Plotly).
3. **Semester 3 (Course 306-02):** Fundamentals of Android (Android Studio, XML layouts, widgets, event handling, Intents).
4. **Semester 3 (Course 306-03):** Fundamentals of Graphic Design with Designing Software (Canva for social media, branding, and presentations).
5. **Semester 3 (AI-306-04):** IoT Data Handling and Basic Smart Systems (Arduino sensor streaming, ThingSpeak cloud integration, real-time dashboards).
6. **Semester 4 (Course 406-01):** Introduction to Machine Learning (Supervised, unsupervised, reinforcement learning overview, Scikit-learn lifecycle).
7. **Semester 4 (Course 406-02):** Data Analysis and Dashboard Reporting using Worksheet / Power BI (Power BI data import, DAX formulas, interactive reporting).
8. **Semester 4 (Course 406-03):** Data Science with Python (Pandas manipulation, data wrangling, machine learning fundamentals).
9. **Semester 4 (AI-406-04):** AI for IoT – Smart Intelligent Systems (Arduino sensor data ML classification, intelligent alert systems).
10. **Semester 5 (Course 506-01):** Working with AI-Based Software (GenAI tools, ChatGPT, prompt writing, video/presentation automation).
11. **Semester 5 (Course 506-02):** Fundamentals of Software Engineering (SDLC models, SRS documentation, UML diagrams, software testing).
