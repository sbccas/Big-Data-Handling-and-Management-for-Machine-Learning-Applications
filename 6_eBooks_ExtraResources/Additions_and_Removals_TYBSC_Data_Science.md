## 2. What Was Added in the New File

### A. Extended University SEC (Skill Enhancement Course) Pool
The major addition in the August 17, 2026 file is the university-wide **Skill Enhancement Course (SEC)** booklet spanning Semesters 1 through 5 for BCA / B.Sc. IT / Data Science specializations:

* **Semester 1:**
  * `AI-106-03`: **Introduction to IoT Devices (SEC-01)** – Arduino Uno hardware, breadboards, basic sensors (LDR, temperature), digital/analog I/O, LED control.
* **Semester 3:**
  * `306-01`: **EDA using Python** – Data types, cleaning missing values/outliers, Pandas manipulation, visualization (Matplotlib, Seaborn, Plotly).
  * `306-02`: **Fundamentals of Android** – Android architecture, XML layouts, widgets, event handling, ListView, Intents.
  * `306-03`: **Fundamentals of Graphic Design with Designing Software** – Canva tools, typography, color theory, social media assets, presentations.
  * `AI-306-04`: **IoT Data Handling and Basic Smart Systems (SEC-02)** – Sensor reading, ThingSpeak cloud platform integration, real-time dashboards.
* **Semester 4:**
  * `406-01`: **Introduction to Machine Learning** – ML workflow, supervised vs. unsupervised learning, Scikit-learn basics, model metrics.
  * `406-02`: **Data Analysis and Dashboard Reporting using Worksheet** – Power BI environment, data cleaning, DAX functions, interactive reports.
  * `406-03`: **Data Science with Python** – Pandas dataframes, exploratory analysis, Matplotlib visualization, introductory ML models.
  * `AI-406-03 / AI-406-04`: **AI for IoT – Smart Intelligent Systems** – Arduino sensor streaming to Python, KNN classification on IoT datasets, smart decision logic.
* **Semester 5:**
  * `506-01`: **Working with AI-Based Software** – Generative AI tools, prompt engineering, ChatGPT, automated video/presentation tools.
  * `506-02`: **Fundamentals of Software Engineering** – SDLC models, SRS documentation, UML diagrams (Use Case, Sequence, Activity), software testing.

## 3. What Was Removed or Modified from the Old File

### A. Removal of "and Analytics" from Course & Degree Titles
* **Old File:** Program and course titles were consistently styled as:
  * `T.Y. B.SC.(DATA SCIENCE AND ANALYTICS) (HONOURS)`
  * `Bachelor of Computer Science in Data Science and Analytics`
  * `B.Sc.(Data Science and Analytics) (Semester-5)`
* **New File:** The term *"and Analytics"* was removed:
  * `T.Y. B.SC. (DATA SCIENCE) (HONOURS)`
  * `Bachelor of Computer Science in Data Science`
  * `B.Sc.(Data Science) (Semester-5)`

### B. Shift in Implementation Academic Year
* **Old File:** Effective date was set to **June, 2026–2027** across all course header sheets.
* **New File:** Effective date is changed to **June, 2027–2028**.

## 4. What Remained Unchanged (Core Subjects & Topics)

All core Semester 5 and Semester 6 subject syllabi, outcomes, and unit contents remain **100% identical**:

* **DS-501 (Cloud Computing Fundamentals):** Cloud models, Virtualization, Hypervisors, AWS/Azure (EC2, S3, Lambda, VPC, RDS), Data Lakes.
* **DS-502 (Computer Network):** OSI/TCP-IP, Subnetting, Routing (RIP, OSPF, BGP), Linux networking commands, Wireshark packet capture.
* **DS-503 (Fundamentals of Machine Learning):** K-Means, Hierarchical clustering, DBSCAN, PCA, Intro to Artificial Neural Networks (ANN).
* **DS-504 (Advanced Data Visualization):** Power BI (DAX measures, Star/Snowflake schemas, drill-down), Tableau Desktop.
* **DS-505 (Big Data Handling for ML):** PySpark DataFrames, distributed computing, Scikit-learn pipelines, Hugging Face Transformers & LLM basics.
* **DS-506 (Ethics of Data Science):** Algorithmic bias, GDPR, Indian Data Protection Act, case studies.
* **DS-601-01 / DS-601-02 (Electives):** E-Commerce & Cyber Security **OR** Computer Graphics.
* **DS-602 (Advanced ML & Neural Networks):** SVM, Random Forest, Gradient Boosting, Deep Neural Networks, CNNs (Convolution/Pooling).
* **DS-603 (Big Data & Cloud-Based ML):** Google Colab cloud storage, Pickle/Joblib serialization, Flask ML APIs.
* **DS-604 (Project) & DS-606 (Internship):** 4-step SDLC project and 120-hour internship framework.
